In this lecture, Joi-sensei begins by explaining the history of web technologies, starting with web 1.0, in which it became possible for people to create websites and e-commerce sites to sell things online. 

Afterward, with web 2.0, mobile began to be more widespread, and search engines from Google and Yahoo empowered people to find things more easily using text-based words or phrases. Moreover, social media platforms like Twitter (now, X) and Facebook (also, Meta) brought in more people to the internet. These people created accounts for others to identify who they were.

Now, web 3.0 aims to create metaverses and virtual reality, while using blockchain technology to move "nft (non-fungible token)" objects like their IDs or things that they've bought online from one platform to another. 

Finally, Joi-sensei concludes that while web 2.0 brought together dispersed people using the internet into a few platforms, web 3.0 intends to again empower people to disperse anew, decentralizing the few, big platforms currently available. In fact, he says that his use of lowercase letters for "web3" is part of the culture that people can grow using this technology.
